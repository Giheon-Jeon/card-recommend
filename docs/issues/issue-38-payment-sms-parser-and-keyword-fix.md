# Issue #114: [BUG] 결제 문자 파싱 시 누적·잔액 금액 오인식 및 키워드 부분 매칭 오탐

## 1. 개요
- **관련 이슈**: `#114` (`QA-001`, `CA-005`, `CA-006`)
- **목적**:
  1. 한국 카드사 승인 문자 끝에 위치하는 `누적`, `잔액`, `한도`, `잔여` 금액이 결제금액으로 오인식되고 상호명이 `"누적"` 등으로 잘못 추출되는 문제를 해결합니다.
  2. 짧은 영문 약어(`KT`, `CU`, `SSG`, `KTX`, `SRT` 등)와 일반어 포함 키워드(`마트` vs `스마트스토어`)의 단순 부분 문자열 매칭 오탐을 방지합니다.
  3. Gemini API 응답 파싱 실패 시 민감한 소비 내역이 포함될 수 있는 `responseText` 원문 로깅을 제거하고, 카테고리 화이트리스트(`categories.json`) 및 유한 정수 금액 검증을 강화합니다.

## 2. 주요 변경 사항
1. **누적·잔액·한도 금액 제외 및 결제금액 우선 추출 (`src/lib/importerParser.ts`)**:
   - `누적`, `총누적`, `누계`, `잔액`, `잔여`, `한도`, `가능액` 바로 뒤에 위치하는 금액과 소괄호 안 카드번호(`(1234)`)를 결제금액 후보에서 제외했습니다.
   - `원` 접미사가 붙은 금액 후보를 우선 선택하며, 후보가 여럿일 경우 승인 키워드(`승인`, `결제`, `취소`, `환불`, `일시불`)에 가장 가까운 금액을 선택하도록 개선했습니다.
   - 가맹점 토큰 정제 시 누적/잔액 구문과 관련 키워드를 제거하여 실제 가맹점명이 정확히 추출되도록 수정했습니다.
2. **키워드 단어 경계 매칭 및 오탐 예외 처리 (`src/lib/importerParser.ts`)**:
   - `matchesCategoryKeyword` 헬퍼 함수를 도입하여 영문 약어 키워드에 영문 단어 경계(`(?<![A-Za-z])...(?![A-Za-z])`)를 적용했습니다 (`"KTX"`가 `"KT"`(`mobile`)에 매칭되는 현상 등 방지).
   - `KEYWORD_MAP.onlineShopping`에 `"스마트스토어"`, `"네이버스마트스토어"`를 추가하고, `"스마트"`가 `"마트"`로 오분류되거나 `"쿠팡이츠"`가 `"쿠팡"`으로 오분류되지 않도록 오탐 예외 패턴을 적용했습니다.
3. **Gemini 응답 로깅 보안 개선 및 출력 유효성 검증 (`src/lib/importerParser.ts`, `src/lib/cardAdvice.ts`)**:
   - JSON 파싱 실패 시 `responseText` 원문 대신 응답 길이(`length`)만 콘솔에 로깅하도록 수정했습니다.
   - `parseWithGemini` 반환값의 카테고리를 `data/categories.json` 허용 ID 집합(`VALID_CATEGORY_IDS`)으로 검증(미등록 값은 `"etc"`로 폴백)하고 금액을 유한 정수(`Math.trunc`)로 정규화했습니다.
4. **단위 테스트 보강 (`tests/importerParser.test.ts`, `tests/cardAdvice.test.ts`)**:
   - QA-001 재현 테스트, 키워드 오탐 방지 테이블 테스트(`it.each`), Gemini 응답 검증 및 원문 미노출 보안 테스트를 추가했습니다.
